## 4. Setup Server AI (Hermes)

### Eksplorasi (read-only)
- Server Ubuntu, Hermes Agent **v0.19.0** di `~/.hermes/hermes-agent`.
- Ada beberapa profile Hermes lain yang sedang berjalan → **tidak disentuh**.
- Hanya port SSH yang terbuka ke publik.
- Hermes punya `api_server` (OpenAI-compatible, mendukung `image_url` base64).
- `hermes proxy` (subscription proxy) **tidak** mendukung `openai-codex` → pakai `api_server`.
- Peringatan dari docs: `api_server` default memberi akses ke **semua tools termasuk terminal** → wajib dibatasi.

### Perubahan pada profile `diet-yuk`
File lama dibackup sebagai `*.bak.<timestamp>` sebelum diubah.

1. **`.env`** — ditambah:
   ```
   API_SERVER_ENABLED=true
   API_SERVER_HOST=127.0.0.1
   API_SERVER_PORT=8642
   API_SERVER_MODEL_NAME=diet-yuk
   API_SERVER_KEY=<openssl rand -hex 32>   # tidak dicantumkan
   ```
2. **`config.yaml`** — `agent.disabled_toolsets` berisi semua toolset (web, browser, terminal, file, code_execution, memory, skills, delegation, cronjob, computer_use, dll). Tersisa hanya `vision`.
3. **`SOUL.md`** — persona diganti: ahli gizi Indonesia, acuan TKPI, tanpa tools, output JSON saja.
4. **Service** — `hermes --profile diet-yuk gateway install --start-now --start-on-login`
   → user service `hermes-gateway-diet-yuk` (enabled, linger aktif).
